## 2. De ce Nivelul 1 primul — rațiunea

**POPY nu are factură fiscală.** Nu se poate organiza ca firmă. Nu poate vinde
serviciu.

**Dar** se poate prezenta. Și un site de prezentare bun este **pachetul care se

## 4. Exact ce intră în fiecare site

**Nu se inventează nimic. Se extrage din:**

```
CV-URI tale (ALEX-KIT/CV-ORIGINALE-POPY/)   ←experiență, roluri, clienți
matricea de linkuri (ALEX_LINK_MATRIX)      ← DOAR linkuri verificate
portofoliul tău                             ← proiecte reale
```

**Structura fixă a fiecărui site** (identică, se schimbă doar conținutul):

```
1. Poziționarea      — rolul, și prin ce e diferit de cel vecin
2. Sumar             — 3 rânduri, din CV-ul de rol
3. Competențe        — din anunț + din CV
4. Realizări        — din CV-ul tău, cifrele tale
5. Portofolio        — proiecte REALE, cu marcarea unde nu sunt publice
6. Scrisoare         — modelul tău, aplicat peste tot
```

## 5. Reguli care nu se încalcă

| Regulă | De ce |
|---|---|
| **Fără nume de firmă în șabloane** | altfel lucrezi de două ori |
| **Fără linkuri video inventate** | se verifică fiecare |
| **`proof of work provided on request`** | pentru ce nu e online |
| **Fără formular de contact la Nivelul 1** | POPY a decis asta — „la finalul finalului" |
| **ATS-friendly** | o coloană, fără tabele, fonturi standard |
| **Un singur site de CV per rol** | nu se amestecă rolurile |
