# Arhivă

Regula: **niciodată ștergere definitivă, doar mutare aici.**

Conținut: handoff-uri vechi, consumate.
Nu se șterge nimic. `git log` păstrează istoricul complet.

**Nu se mută aici:** fișierele de doctrină și configurare
(`REGULI-PLATFORMA.md`, `DEFINITIE-OPERATIONALA.md`, `BRIDGE.md`,
`JULES-INSTRUMENTARE.md`, `TODO.json`, `LOG-SISTEM.json`,
`MANUAL DE NAVIGARE - cotor.md`), datele din `SITE/date/`,
șabloanele din `ALEX-KIT/TEMPLATES-POPY/`.
